# Contributing

Thank you for your interest in contributing to Robusta!

> [!IMPORTANT]
> Please read [AGENTS.md](./AGENTS.md) for the prerequisites, development commands, and where to add tests.

Please check out the [open issues](https://github.com/robusta-rs/robusta/issues), or open one to report a bug or ask for guidance.

We welcome and appreciate any form of contributions.

## AI Usage Policy

When using AI tools (including LLMs like ChatGPT, Claude, Copilot, etc.) to contribute to Robusta:

- **You are responsible** for every AI-assisted change you submit
- **Review, test, and understand** every AI-assisted change before you submit it

We encourage the use of AI tools to assist with development. AI-generated code must meet Robusta's performance and quality standards.
